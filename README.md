Public release channel for the Voltage Drop Calculator.

[Download the latest Windows executable](https://github.com/cszmw2k6dk-design/voltage-drop-releases/raw/main/VoltageDropCalculator.exe)

## Online update

The desktop application checks `update.json` in this repository, verifies the
downloaded file with SHA-256, replaces the current executable, and restarts.
